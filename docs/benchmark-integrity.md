# Benchmark integrity

Realism comes first. Export actual daily message records losslessly and deliver them through the provider's documented native ingestion. Preserve sender, channel, thread, written time and collection time. Format conversion is allowed; benchmark summaries, invented assistant turns, seeded facts and custom extraction instructions are not. Memcal receives a provider-independent synthetic Apple Messages database and separate contacts source through its native reader.

Only practical local backends qualify. Document ingestion and authentic message capture both qualify; cloud-only services and impractical extraction workarounds do not. Queue acceptance is not completed processing. Fail readiness checks honestly and keep the current evidence sufficient to diagnose failure.

Hermes starts fresh after ingestion with no source chat history or populated built-in memory. Its actual system prompt must contain no benchmark project context. Only exact tools shipped by the provider are exposed and executable. Non-provider attempts fail before execution. This is a tool boundary, not an OS sandbox; native provider internals can use files and models normally.

Freeze verified dialogue, evidence-cited facts, public questions and the recovery policy before provider execution. Do not tune prompts or grading to favor a provider. Private authoring facts never enter the assistant's question. The semantic judge decides correctness; code checks structure and provenance, not lexical answer matches. Malformed judgments leave answers ungraded.

Use scenario-local clocks with explicit offsets. Eastern means `America/New_York`, including DST. Evaluation cannot precede source availability or native processing. Multiple evaluation turns may share a real fresh session, but previous answers cannot earn facts omitted from the current answer; source fallback in that history invalidates later retention.

Log actual arguments/results, failures, retries, latency, agent tokens, provider model activity and available native internal tools. Original-source/archive fallback fails retention. Unknown operation classifications receive no retention credit; unknown cost remains unknown. All Spark inference goes through the shared gateway, under $10 total and $5 per UTC day.

Development artifacts and obsolete protocols are disposable. Keep only the latest Pizza Day test and necessary authoring/source/audit evidence. Delete old results and code rather than adding compatibility or historical invalidity UI. Preserve the shared spending ledger, runtime dependencies and credentials outside Git. Start small and increase complexity gradually. Commit coherent changes; fix and commit Memcal product bugs in the Memcal repository.
