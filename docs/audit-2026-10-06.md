## Recommended native setup

Holographic uses its bundled local store and defaults. Memcal copies its actual
Hermes plugin into a scratch profile and bootstraps an empty native DB/brief.
Local OSS Mem0 uses the plugin README's documented Ollama embedder and Qdrant
vector store with Contributor extraction through the shared OpenAI-compatible
gateway. The SDK dependencies are pinned in the Hermes extras file. Ollama
v0.35.1 runs CPU-only on localhost:11435; its official nomic-embed-text manifest
and blobs were SHA-256 verified. No fake embeddings or paid embedding service.

The pinned top-level Hermes CLI rejects setup flags documented in its Mem0
README. The failed invocation is saved. The fallback uses the README's manual
mem0.json route and the plugin's own builder/save methods. sync_max_chars=6000
follows the documented recommendation for an 8k embedder. Identities and store
paths are run-owned; native default agent_id remains unchanged. No vendor code
or memory prompts are altered.

All providers receive the same ordinary transcript handoff, with no private
scene/claims or forced tool choices. Normal additive built-in memory remains;
session search is disabled and recall starts a new session. This simulates a
user sharing messages with Hermes, not a native iMessage account on Linux.
